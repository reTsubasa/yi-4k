# 真机 EIS 连续观测证据

设备：普通 YI 4K / YDXJ2_V13LW / 1.10.7。完整解释及复现方式见 [报告](../../../docs/device-live-eis-observation.md)。

- `stock-eis-01/`：260 个 20 Hz 只读 DRAM 样本。尝试一次 API 录像，开始、清理停止、关闭会话均无成功回复；用户确认正常取景、没有录像计时。不得作为成功录像基线。
- `readonly-osync-01/`：40 个 10 Hz 只读样本，使用 O_SYNC 作对照，没有录像请求。
- `readonly-task-01/`：40 个 10 Hz 只读样本，增加任务栈、通信对象、系统 tick，没有 API 请求。
- `api-evidence/`：从本机提取的三个 ELF 库导出的选定函数反汇编及 PLT 索引。
- `reboot-recovery-01/`：用户确认死机并正常重启后，Linux 和原厂 API 查询成功；没有运行内存探针。
- `reboot-api-only-01/`：无内存探针的原厂 API 短录像，开始/停止成功；保留下载视频、伴随文件和主视频完整解码验证。停止后立即状态为 Unknown，稍后独立查询为 idle。
- `sha256.json`：本目录证据和本轮工具、报告的相对路径与 SHA-256；不包括自身。

各采集目录保存实际 `target-probe.py`、原始 Telnet 输出、样本 JSONL、字段 CSV、离线统计与会话元数据。工具后来修改不影响当时目标程序的可追溯性。内存读取没有 cache 同步，不能默认所有字段同时、实时、跨核一致。

用户已确认此前相机死机。直接内存探针目前暂停真机执行；只读不表示无运行扰动，采集文件完整不能证明设备运行稳定或探针安全。死机原因尚未隔离确认。
