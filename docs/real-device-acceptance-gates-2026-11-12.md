# YI 4K 真机验收关卡与回滚手册

更新时间：2026-11-12。本文把四条主线尚缺的真机证据收敛为可审阅的顺序。它本身不连接设备、不写固件/RAM/分区、不写 RTC、不启动录像，也不安装运行期 hook。

## 已完成的安全前置

当前设备身份固定为 `YDXJ2_V13LW` / `Z16V13L_1.10.7_build-20180202122459_git-a8f840ce_r2746`。只读 readiness 04 前后均为 `idle`，EIS 为 `on`，SD 为 `insert`；RTSP 04 解码真实 848×480 H.264 首帧后恢复 `idle`；语音设置 02 没有公开 `voice_*` 或 `keyword_*` 字段。所有回执均保留 SHA-256。

Android 0.5.0 的主机门禁为 214 项单测、Lint 0 errors、APK 构建通过；实体 Android 设备当前不可见（本机没有 `adb`），因此安装、刘海/横屏、触感、飞入动画和自动连接仍需现场设备。

## 关卡顺序

| 关卡 | 运行内容 | 成功证据 | 失败/回滚 |
| --- | --- | --- | --- |
| G0 | 只读状态、固件、SD、EIS、RTSP 和设置快照 | 前后状态、boot ID、设置 SHA、RTSP 首帧/包清单 | 停止后续步骤；不改变设备 |
| G1 | Android 实体机安装 APK，连接相机热点，验证横屏/安全区/OSD/快门反馈/飞入/自动连接 | APK SHA、录屏/截图、连接日志、拍摄回执 | 卸载 APK，清除应用连接元数据；相机保持原状 |
| G2 | EIS 原生执行最小一次性 marker：只验证入口→返回→清理，不触碰 EIS 表、DSP、编码或 SD | 入口/返回/错误码、任务前后快照、清理后文件清单、冷启动恢复 | 立即断开入口、删除已核验临时文件；若状态不确定保持文件和快照，禁止猜测清理 |
| G3 | EIS 算法替换前置 A/B：只读采集同场景真实 gyro、帧时间和原厂视频，生成候选离线回放 | 原厂/候选输入 SHA、逐帧时间表、画质指标 | 只保留归档，不写回相机；候选不满足 ABI/回退门禁时拒绝上机 |
| G4 | 预录后端验收：先普通录像基线，再经批准的 callback/FIFO/实体 SD ring，验证 60 秒历史、触发后段、原厂 mux 和播放 | 触发前后 H.264/AAC 包、manifest、MP4 SHA、独立解码、SD/掉电失败回执 | 关闭新 owner，保留未确认段；不调用原厂 loop 删除；仅删除本 session 已核验文件 |
| G5 | 语音/快门绑定：分别由相机识别“开始录像”/`start recording` 和实体快门触发同一状态机，验证重复事件只提交一次 | 每路事件原始回执、commit token、同 SHA 成片、去重日志 | 事件识别/送达不明时保持 UNKNOWN；不把超时当失败或成功 |

## EIS 运行期硬门

G2 通过前不得执行自定义 EIS；G2 通过也不等于 DSP 发布完成。算法替换必须另外证明 I-cache/ISB、SMP 可见性、DSP latch/ack、旧表安全释放和编码帧关联。任何一项缺失都只能保留离线候选状态。

## 预录发布硬门

只有在 callback 静止、payload 已复制到自有存储、共同 A/V epoch、参数集/IDR、AAC 边界、原厂 Close/Open 和实体 SD 持久化全部有证据时，才允许发布 MP4。缺包、Close 短写、掉电、拔卡、校验篡改都必须保留 manifest 并拒绝发布；不能把 host mux 或 typed event 结果升级为真机完成。

## 当前待授权动作

G1 只需要实体 Android 设备；G2–G5 会改变相机运行状态或写入相机媒体/运行期资源，执行前必须对具体关卡单独确认。未获确认前，继续推进离线门禁、只读观测、Android 主机测试和证据整理。
