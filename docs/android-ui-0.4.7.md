# Android 0.4.7：拍摄原型、全屏叠层与设置整理

2026-11-12。本版按用户提供的纵屏/横屏原型调整实际 Android 界面。版本号 0.4.7，versionCode 30。

## 拍摄界面

- 移除覆盖顶部连接状态的消息条。短反馈使用系统 Toast；导出进度和取消操作使用工作区下方的独立行，普通通信不占位。
- 参数栏改为单行胶囊：RES、FPS、FOV、EV、COLOR；首项橙色，其余浅色细边。值读取相机实际设置，拍照时隐藏不适用的 FPS，窄屏/大字体可横向滚动。电子防抖保留在 OSD，点击可查询相机选项。
- 画面默认铺满，消除容器比例与视频不一致造成的黑边；提供“铺满 / 完整”切换。铺满会裁去边缘，完整模式保留源画面比例并允许必要留边，不修改相机录像文件。
- OSD 使用浅色半透明胶囊，避免整条参数重复叠加；保留实际规格、视角、防抖/预览失败、拍摄状态。未取得相机录制计时，因此不伪造 REC 时长。
- 全屏将同一个预览容器和控制对象重挂到全窗口层；快门、模式和缩略图位于底部，常用参数在右侧，状态在顶部。按实际窗口尺寸适配横竖屏；返回键退出全屏，打开设置/相册会恢复普通布局。
- 修复全屏退出保留旧控制区宽度/边距的问题，以及跨页面后缩放按钮文案与实际模式不一致的问题。

## 设置清理

对固定 1.10.7 注册表的全部 96 项逐一核对，均有中文名称（[逐项清单](../artifacts/android/0.4.7-host-reports/setting-label-inventory.json)）。序列号、相机热点名称/密码、外部网络名称/密码等原来漏译的真实字段均使用中文名称，原协议 key 保留在数据层。密码显示为掩码。设置行仅保留中文名称、当前值和必要操作；删除每行重复的泛化说明和只读标记。

能力位、`support_*`、`*_settable`、运行中状态、未开放的重置/动作入口不再作为可调整参数。兼容字段成对出现时只显示规范项；热点模式下为空的外部网络凭据隐藏，实际配置或客户端模式下仍可查看。所有过滤通过 `SettingsHierarchy.hiddenReason()` 返回明确理由，原始 JSON 不改动。有效影像、特殊拍摄、录音、网络和电源参数保留。

相机时间在日期时间行提供“同步”，写入后读回校验，避免另加重复说明卡片。序列号、固件、存储卡状态和网络凭据不再显示可编辑箭头。仅在相机实际返回语音字段时显示相应中文条目；没有伪造语音开关或增加无效诊断占位。原厂相机本机语音能力与 Wi-Fi API 是否提供开关是两回事，见[语音复用与关键词替换](voice-keyword-replacement-path.md)。

## 验证与边界

构建、测试计数、Lint、APK 和截图摘要集中在[构建回执](../artifacts/android/2026-11-12-build-0.4.7.json)。206 项主机单测通过，Lint 为 0 errors / 74 warnings。主机原生渲染覆盖窄屏、大字体、横竖屏、全屏重复进入/退出、导航恢复、同一预览容器和控件可达性。实际 AVD 进一步发现并修复全屏退出后参数栏高度恢复不及时导致上缘裁切的问题；历史失败回执保留。同一最终 APK 的[实际 AVD run04](../artifacts/android/0.4.7-device-reports/ui-review-run04/acceptance.json)完成 3 项测试：中文设置名称/值无重叠、普通旋转保留容器、真实触摸全屏进入→横屏→竖屏→退出→设置。五阶段保持同一个预览容器；退出后五个参数均完整可见。未使用真实 RTSP 源，不能把容器身份当作真实解码会话证明。

本轮未安装实体手机、未连接或修改相机。模拟器和主机渲染不能证明实体手机的刘海/旋转锁、RTSP 填充裁切、热点或相机语音识别效果；本版也没有把 EIS 替换或一分钟预录接入 App。
