# 拍照后的真实照片飞入相册

`CaptureAlbumFeedback` 提供快门左侧的 48dp 相册缩略图入口。无真实封面时显示相册线条图标；只有新照片完成拍摄、调用方发现其媒体条目并取得真实缩略图后，才播放“照片预览飞入相册”的动画。加载失败不生成假照片，不替换旧封面。

动画从当前取景器中心开始，560ms 内沿曲线缩小到相册入口。飞行图放在窗口 overlay，快门、模式栏和相册按钮的布局尺寸、位置不变化。已有照片通过 `setThumbnail` 填充封面，不误报一次新拍摄。

所有 helper 方法在主线程调用。`setThumbnail` 和 `play` 都创建不超过 384px 的独立副本，不修改或回收调用方 bitmap；缩略图回调在方法返回后即可回收原输入。导航或后台调用 `cancel`，移除飞行 overlay 并释放尚在飞行的副本；销毁或重建拍摄页调用 `close`，先移除 drawable，再释放自己的封面副本。

这里没有媒体查询或 HTTP 请求。相机同会话的新照片发现、拍摄完成状态、缩略图请求和连接代次检查由 `MainActivity` 负责。原 API 请求应继续在串行 commands executor 中完成；照片下载由 `CameraThumbnailStore` 自身 worker 执行，回调在主线程。

新增主机回归覆盖输入图像被修改、回收后仍显示原始真实像素，隐藏页面不播放动画且保留真实封面，失败保持旧封面，以及 helper 不夺取输入 bitmap 所有权。实际飞行动画和拍摄接缝的验证由本版组合验收记录；本说明不将 helper 单独存在视为真实相机拍照验证。
