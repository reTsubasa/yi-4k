# Android 0.3.16：拍摄工作台布局稳定与素材预览

本版继续按用户提供的原型和实机截图收口 Android UI。没有访问或写入相机固件、RAM、分区或启动区。

## 本版变化

- 未连接时连接页仍是 App 首屏，进入页面立即搜索附近 Wi‑Fi，只保留 `YDXJ` 前缀候选；不显示手动 IP 输入，首次扫描结束后才提供“重新搜索”。
- 拍摄页顶部改为“相机控制”，设备型号只在状态卡显示，避免型号重复。状态卡显示型号、Wi‑Fi 质量（灯色和文字）、电池百分比与红/黄/绿填充、SD 状态或固件提供的容量百分比。
- 连接成功后自动尝试实时画面；切换录像/照片/延时/慢动作或规格后自动重建预览。全屏监看保持独立入口。
- 快门区取消相册/连接误触入口。快门保留金属环和录像状态绘制，增加即时缩放与触感反馈；原生状态动画被禁用，轮询不会重复触发视觉过渡。
- 操作、取消导出和完成提示共用一个固定高度状态槽。提示出现或消失不会改变快门区、模式栏或预览的测量高度。
- 分辨率选项的规格标签保持单行横向滚动；当前项使用浅蓝背景、蓝色描边和强调色标签。全局强调色统一为 `#007AFF`。
- 设置页无全局搜索和连接管理卡片；一级分类、二级分组和白色分组卡片保留所有参数，当前值使用强调色胶囊/单选勾选。
- 素材库默认加载记忆目录，文件夹使用统一卡片行；网格默认加载缓存视频封面，并对符合大小限制的照片自动读取真实封面，去掉每张卡片的“读取照片封面”按钮，保持两列对齐。
