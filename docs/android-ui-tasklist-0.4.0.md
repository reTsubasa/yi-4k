# Android 0.4.0 界面整改任务

按 2026-11-11 用户的 10 项反馈逐项实现与验收。此清单中的“待验收”不能算作完成；实际截图、测试和 APK 在交付时补齐。

| 编号 | 任务 | 状态 | 验收标准 |
| --- | --- | --- | --- |
| 1 | 统一选项弹层 | 已实现（主机/AVD） | 通用参数与规格使用同一底部圆角面板，当前项明确，无原生单选框混用 |
| 2 | 设置返回导航 | 已实现（主机/AVD） | 返回在子页左上，融入标题，不再出现居中独立按钮 |
| 3 | 统一配色并落盘 | 已实现（主机/AVD） | 石墨黑、暖灰基础色，组件遵循共享色板，语义颜色有区分 |
| 4 | 连接返回导航 | 已实现（主机/AVD） | 页头内的轻量返回，不占用独立整行按钮 |
| 5 | 分辨率与标签对齐 | 已实现（主机/AVD） | 标签单行，右侧对齐，按分辨率/帧率/视角/限制分类 |
| 6 | 移除通信文案和占位 | 已实现（主机/AVD） | 普通通信不占用页面高度，拍摄区不因提示伸缩，错误与导出仍有反馈 |
| 7 | 快门左侧相册与新照片动画 | 已实现（主机单测） | 可点击的真实缩略图，新照片确认及读取后，以照片预览飞入；失败不伪造成功 |
| 8 | 相册命名统一 | 已实现（主机/AVD） | 导航、页头、入口及返回中统一“相册” |
| 9 | 剪辑整体复核 | 部分（已有回归） | 选片、预览、裁剪、效果、导出和取消可用；实体手机和真实长片仍待验收 |
| 10 | 相机型号标题与状态/容量 | 已实现（代码/主机） | 型号直接作拍摄标题，状态区不重复型号；真实相机数据仍需实体手机确认 |

验证：主机单元测试 174 项、Lint 0 errors/64 warnings、AOSP34 ARM64 系统合成器 2 项通过，证据见 [0.4.0 构建](../artifacts/android/2026-11-11-build-0.4.0.json) 和 [UI layout run05](../artifacts/android/0.4.0-device-reports/ui-layout-run05/acceptance.json)。实体手机仍需手动安装验收；EIS 和一分钟相机预录仍按三主线目标推进，不因界面整改宣布完成。
