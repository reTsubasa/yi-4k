# Android 0.5.0 UI 与连接任务清单

来源：用户提供的全屏拍摄页原型及 2026-11-12 反馈。所有视觉任务都以真实取景画面可见、控件可点击、手机刘海/状态栏不遮挡为验收条件。

本轮完整问题清单：移除遮挡取景的顶部消息；全屏横向并适配刘海；按原型重排快门、相册、模式和参数展示；降低面板底色、提高区域对比度；移除 App 咔擦声并提供实时取景帧飞入相册；保存相机连接信息并在冷启动自动连接；更多设置使用中文项目名并清理重复/无效项；相机时间同步入口保持显式控制；EIS 原生执行、算法替换和一分钟预录继续同步推进。

## 拍摄页与全屏

- [x] 全屏取景器铺满可用窗口，自动横向；根据 display cutout 和系统安全区定位顶部状态栏（代码/单测完成，实体手机待验收）。
- [x] 顶部状态、左侧快捷项、右侧参数、底部模式栏采用半透明液态玻璃叠层，避免大面积不透明底色遮挡画面。
- [x] 不同区域保持清晰层级和足够对比度：状态、参数、选中模式、录像状态、快门动作可区分。
- [x] 右侧参数按原型纵向排列，分辨率使用强调色；参数项主要用于展示，不表现为一组可点击按钮。
- [x] 相册入口、快门和模式栏按原型位置对齐；相册缩略图与快门中心线稳定。
- [x] 移除 App 自己播放的相机咔擦声；保留必要的视觉/触感反馈，系统静音策略由系统控制。
- [x] 点击快门后从当前取景器帧启动真实缩略图飞入相册动画；动画不等待相机响应，真实 JPEG 到达后替换临时缩略图。
- [x] 移除取景区域顶部遮挡性消息；连接/导出状态放入不覆盖取景的状态槽。

## 连接体验

- [x] 加密保存已成功连接的相机 SSID、地址和连接参数（密码仍由 Android Keystore 保存）。
- [x] 冷启动检测已保存配置；相机 Wi-Fi 已可用且协议连接成功时直接进入拍摄页。
- [x] 自动连接失败时回到连接页并给出明确原因，允许手动选择其他相机；不重复发送拍摄命令。
- [x] 自动连接路径覆盖断网、密码失效和相机不可达恢复；不记录明文密码。

## 设置与相机时间

- [x] 更多设置的已支持参数使用中文项目名；保留底层键用于协议交互。
- [x] 设置页按功能分组并清理重复、无效入口；未知固件字段仍以诊断信息保留。
- [x] 相机时间同步有显式开关和读回契约，默认不写入相机；真实 RTC 写入/读回列入真机验收。

## 验证与发布

- [x] 主机 UI/连接单测、Lint、Debug APK 构建通过（212 项，0 failures/errors；Lint 0 errors/74 warnings）。
- [ ] AVD/实体 Android 设备验收记录刘海、横竖屏、参数可读性、快门/飞入动画和自动连接。
- [x] 更新 Android 交付说明、构建回执、APK SHA-256 和目标证据矩阵。

## 并行底层主线

- [ ] EIS 原生执行：继续只读证据、入口安全边界和失败可恢复门禁；真机写入需单独批准。
- [ ] EIS 算法替换：候选算法保持离线可回放，补齐真实 gyro/视频共同时间锚、画质对照和回退方案。
- [ ] 一分钟预录：继续原厂编码/封装、C spool/SD 恢复、语音 START 和快门 typed trigger；补齐真机事件、实体 SD 和可播放成片验收。

当前清单不把主机模拟或离线回放升级为真机完成证据。
