# Android 视觉系统：象牙纸色与陶土橙

本版依照新的 editorial 纸感参考，统一采用象牙暖白 `#F4EFE7` 和陶土橙 `#C4622D`。底色、表面与分隔线保持暖色关系，深棕黑用于正文；橙色只承担当前选择、主要操作与重点反馈。颜色集中在 `AppPalette.java`，参数弹层集中在 `CameraOptionSheet.java`，不再保留原生青色单选框或蓝色参数按钮。

| 用途 | 背景 / 描边 | 文字 |
| --- | --- | --- |
| 主操作 / 当前导航 | 陶土橙 `#C4622D` | 象牙暖白 |
| 页面底色 | 象牙 `#F4EFE7` | 深棕黑 `#24211D` |
| 纸面 / 弹层 | 纸白 `#FBF7F0` | 深棕黑 `#24211D` |
| 次要文字 | — | 暖灰 `#8B8074` |
| 细分隔线 | `#DDD3C6` | — |
| 当前选项 | `#EFE1D3`，陶土橙细边 | 深棕黑加粗，陶土橙勾选 |
| 分辨率标签 | taupe `#E9E1D7` | `#716150` |
| 帧率 / 慢动作标签 | 灰绿 `#E4E8DB` | `#5F6C51` |
| 视角标签 | 赭黄 `#F0E2BD` | `#8C6D2C` |
| 无 EIS 标签 | 浅陶土 `#EED4C3` | `#A64E23` |

电量与连接质量继续使用红、黄、绿表达状态；快门红色用于录像，不作为普通按钮强调色。标签类别只表明已知选项特征，EIS 仅在相机确认当前规格不支持时标出，不根据分辨率推测其他规格能力。

选项弹层固定为底部纸面，最大宽度 600dp，屏幕左右各留 12dp，圆角 24dp，底部间距 12dp。上方含低对比拖柄视觉、左对齐衬线标题与右上角关闭入口。普通选项以纸面和 hairline 分隔组织，避免成串灰色大卡片；每项至少 70dp 高，当前选项使用浅陶土填充、细边与橙色勾选。所有普通参数、视频规格与只读信息使用同一组件。取消可以点右上角、系统返回或遮罩。

规格行左侧是名称和尺寸说明，右侧是每行一致的标签列与独立勾选列。标签保持单行，横向间距 4dp；同一字体倍率使用一致标签高度，避免中英文字体回退造成上下错位。超出时可横向滑动，不增加行高。分辨率、帧率、视角、EIS 使用四个相互协调的暖系类别色，标签尾端及勾选位置固定。选中状态不改变标签类别颜色。

`CameraOptionSheetTest` 覆盖通用弹层选项索引、底部定位、自定义行、无原生 radio，以及 312/360dp 规格行的标签列对齐、单行与颜色类别；原生主机渲染保存在 `android/app/build/reports/option-sheet-renders/`。这些是主机测试，实体设备显示与触感仍由手动验收覆盖。
