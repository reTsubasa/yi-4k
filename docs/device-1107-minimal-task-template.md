# YI 4K 1.10.7：最小任务模板

[`yi4k_1107_minimal_task.c`](../sdk/yi4k_1107_minimal_task.c) 是一个仅用于静态 ABI 检查的
任务入口。它不包含固定 RTOS 地址，也不执行文件、日志、缓存、GUI、EIS 或 DMA 操作。
调用者把一个 32 位上下文地址作为 entry 参数传入后，入口依次写入：

| 偏移 | 标记 |
|---:|---|
| `+0x00` | `0x59494D31`，已进入 |
| `+0x04` | 原始 entry 参数 |
| `+0x08` | `0x59494D32`，即将返回 |

模板对应的候选 ABI 是：

```c
void entry(uint32_t arg);
```

静态任务闭环需要另行提供自己的 `0xD8` 控制块、栈和上下文缓冲，并按
`TaskCreate(auto_start=0)` → `TaskSmpCoreExclusionSet` → `TaskResume` 的顺序调用。
入口返回后，外层会把线程移出调度结构，但不会自动执行 `TaskDelete`；因此外部控制路径
必须在确认返回后回收对象，或者让对象保持完整直到重启。

当前模板没有真机加载入口，不能直接复制到 SD 卡执行。编译通过只证明 ARM 指令集、入口
参数宽度和源码约束一致，不证明代码所在地址可执行、缓存已同步或 RTOS 能安全调用它。
