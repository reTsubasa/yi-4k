# Android 0.3.15：九项界面与连接反馈

本版按用户实机截图修改 Android App，交付 APK 供用户手动安装。没有向真实相机写入固件或部署逆向代码。

## 行为变化

1. 顶栏使用相机返回的型号，移除 APEX 占位文字；未连接显示“相机”。原厂型号尾缀 Action Camera 不作为型号显示。
2. 电池图标按实际百分比填充：0–20% 红、21–50% 黄、51–100% 绿；未取得数据时显示灰色与 `--`。
3. 连接成功进入拍摄页、返回拍摄页或从后台恢复时自动连接实时画面；切换录像、照片、延时、慢动作以及配置规格后自动重建预览。预览失败最多额外重试两次，仍可手动重试。切页、后台和断网取消过期预览任务并释放本地播放器。
4. 五秒状态轮询改为独立后台刷新，不禁用快门和导航、不插入通信提示。模式按钮只在选中状态变化时替换背景，快门绘制对象保持稳定。
5. 素材库工具行采用一致的左右边界和 8dp 间距；目录放在素材网格之前。剪辑入口和编辑器工具增加行间距，编辑器窄屏工具改为两列；原片查看页时间栏和信息卡适配小屏与大字体。
6. 分辨率选项提供中文名称、尺寸、右侧规格/帧率/视角标签及文本筛选，选择仍提交相机原始值。2.7K 不冒称 2K；“无EIS”只标记本机明确报告不支持的当前规格，不推断其他选项能力。
7. 连接页在 App 内搜索 `YDXJ` 前缀 Wi-Fi，按信号排序并去重；点击候选、填写相机密码、确认 Android 系统连接请求。相机地址由所选网络推导，不要求用户输入 IP。密码可通过 Android Keystore 加密记忆，提供权限、定位、Wi-Fi 开关、超时和取消提示。
8. 设置改为七个一级分类、十七个二级小类，移除全局搜索框；当前值使用蓝色强调胶囊并与说明分离。全部相机返回字段仍可访问，写权限和相机选项校验保持原有规则；未知字段保留在更多设置，不开放格式化、重置或升级动作。
9. 快门采用矢量金属环、内环与渐变按压效果；录像为红色圆形、拍照为白色圆形，录像中变为停止方形。

## 验证范围

主机 native Android 渲染输入为模拟相机数据，不是真实手机截图或实时相机画面。模拟器本地验收验证 Android 组件、布局及媒体/编辑流程，不能证明物理手机射频扫描、热点连接授权与真机 RTSP 模式切换正常。上述三项仍由用户手动测试。

本版修改没有把历史 0.3.13/0.3.14 的真实相机、超大文件或进程终止恢复结果算作本版复测。相机端 EIS 替换、固定一分钟预录及相机语音触发不属于本版已实现功能。
