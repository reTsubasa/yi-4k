# Android 0.4.2：连接、相册与剪辑流程

版本 0.4.2（25），2026-11-11。安装包与最终测试证据见 `artifacts/android/2026-11-11-build-0.4.2.json`。

- App 启动进入连接页，不再根据旧的“已看过引导”标记跳到未连接拍摄页。连接首页无返回按钮；系统返回退出，输入密码步骤返回设备列表。已连接的连接页保留“进入拍摄”和断开操作。
- 点击热点后在页面中填写密码、选择记住密码并连接；无 App 密码对话框。Android 的系统网络授权仍由系统显示。
- 相册进入后自动读取 DCIM 及子目录，汇总照片和视频；不再显示目录卡片、路径或“上一级”。刷新重读整个素材库。同名素材保留完整路径身份。任一子目录失败或列表不完整时，不发布局部快照；保留既有素材并提供重试。空结果不自动循环刷新。
- 剪辑 Tab 先选手机视频，再进入编辑页；系统选片返回的读权限传给编辑器，实际导入成功后才展示时间轴和导出。相机视频详情提供“在剪辑中打开”，先独立复制到编辑缓存，关闭原片预览不会误删素材。
- 编辑页将更换素材收进文件名旁的轻操作，预览移除重复的播放器菜单，播放与选区操作集中在时间轴区域；起点/终点滑条收进可展开的“精确调整”。保留截取、静音、黑白、旋转、播放片段、保存副本和取消。读取失败/取消后可继续选片。
- 相册、剪辑和设置根标题统一为 22sp、相同位置和字体；拍摄页移除顶部标题行。四个底栏标签使用同一组件。共享背景采用象牙暖白顶色、底部暖色渐变与细纸纤维纹理，保留陶土橙操作色。

验证范围：主机回归、Lint、Android 模拟器实际触摸/选片/导出与布局截图。最终数量、APK 摘要和源码摘要以构建证据为准。本版未增加实体手机或相机 RTOS 验收证据。

首轮 AVD 的测试监视器遗漏 video MIME，实际选片已启动但拦截断言失败；同时系统 Recent 未及时列出新夹具。第二轮补全 MIME 匹配和等待后 6 项通过。精简编辑布局后的第三轮也出现系统 Recent 空列表；测试增加通过真实抽屉进入 Videos/Acceptance 的路径，继续使用系统 UI 选择文件，不注入选片结果。第四轮诊断还发现预览图标的辅助描述包含文件名；测试已限定点击文件名文字，防止误进系统播放器。最终验收以构建证据中的报告为准；失败轮原始日志和截图保留。

最终验证：191 项主机测试通过，Lint 0 errors / 66 warnings，AOSP34 ARM64 模拟器 6 项通过。报告为 `artifacts/android/0.4.2-device-reports/ui-flow-run05/acceptance.json`，覆盖页面内密码、自动目录汇总、选片入口真实触摸、分辨率标题/标签触摸、相册多选、旋转、设置和实际系统选片/Media3 导出。模拟器已停止并回收可重建运行磁盘。
